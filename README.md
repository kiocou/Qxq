## 软件介绍

Qxq 是面向 Windows 与 macOS 的截图和效率工具，强调快捷、清晰、低打扰的交互体验。

- 🚀 **插件系统**：按需获得视频录制、文本识别、翻译和 AI 对话等能力
- ✏️ **标注工具**：矩形、圆形、箭头、文字、马赛克等常用编辑能力
- 🎯 **智能识别**：支持全屏、窗口、滚动截图与焦点窗口等模式
- ⌨️ **快捷操作**：支持自定义快捷键和悬浮工具栏
- 💾 **灵活输出**：保存到本地、复制到剪贴板或固定到屏幕

## 下载安装

从 [Qxq Releases](https://github.com/kiocou/Qxq/releases/latest) 下载最新安装包：

- 标准 Windows 安装包：`Qxq_*_windows-x64_setup.exe`
- 内置 WebView2：`Qxq_*_windows-x64_webview_setup.exe`
- 离线资源版：`Qxq_*_windows-x64_offline_setup.exe`
